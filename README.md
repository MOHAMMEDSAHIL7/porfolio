## Run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/your-repo-name.git
   ```
2. Open `index.html` in any browser, or open the folder in VS Code and use the **Live Server** extension.

## Deploy with GitHub Pages

1. Push `index.html` and `README.md` to the `main` branch.
2. In the repository, go to **Settings**, then **Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Choose branch **main** and folder **/ (root)**, then click **Save**.
5. After a minute, your site is live at `https://your-username.github.io/your-repo-name/`.

## Customize

- **Text:** edit the content inside `index.html`.
- **Colours:** change the variables at the top of the `<style>` block (`--bg`, `--brand`, `--accent` and so on).
- **Photo:** the photo is embedded in the `<img class="photo">` tag. To change it, replace that `src` with a new image file path, for example `src="photo.jpg"`.
